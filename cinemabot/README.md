# CinemaBot

Public-facing Jungle Star movie/show review room.

## Planned structure

- `index.html` — CinemaBot landing/review hub
- `reviews/` — one crawlable page per finished movie/show review
- `assets/` — CinemaBot-specific images, posters, thumbnails, and room art
- `data/` — optional structured review metadata later

## Public metadata standard

Each published review should carry:

- title
- movie/show name
- year
- media type
- review headline
- reviewer/author
- date published
- date updated
- spoiler status
- review body
- tags/themes
- canonical URL
- Open Graph metadata
- JSON-LD review/media schema where appropriate

## Build rule

Founder edits/reviews one page at a time before it is linked into the public site.

CinemaBot keeps its own visual identity while staying inside the Jungle Star site family.
