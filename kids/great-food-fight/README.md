# The Great Food Fight — Jungle Star Kids

This folder is the public-site home for The Great Food Fight inside Jungle Star Kids.

## Public route plan

- `/kids/great-food-fight/` — franchise hub
- `/kids/great-food-fight/characters/` — public character pages
- `/kids/great-food-fight/stories/` — readable story/performance-script library
- `/kids/great-food-fight/play/` — public playable games / online mode links
- `/kids/great-food-fight/listen/` — soundtrack and character music
- `/kids/great-food-fight/learn/` — classroom / nutrition / city-systems learning
- `/kids/great-food-fight/shop/` — approved merchandise and preorder links

## Performance-script publishing law

The source/canon script stays intact first. Public pages may add reader headers, cast, timeline placement, read time, teacher notes, song/visual cues, and related links, but they do not silently replace or shorten the source script.

Recovery flow:

`SOURCE ORIGINAL -> CANON REVIEW -> FOUNDER APPROVAL -> READABLE PUBLIC SCRIPT -> OPTIONAL VIDEO/AUDIO/GAME ADAPTATION`

Do not publish drafts marked SOURCE-SEEDED, NEEDS REVIEW, or SOURCE RECOVERY as final canon.
